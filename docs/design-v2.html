一句话定位

一条悬浮在桌面上的"个人 agent 语音通讯录"：把你订阅的各家常驻 agent（ChatGPT dot、Grok Bot、Copilot、Muse、Devin）当成一排可呼叫的联系人，一键呼叫、一键闭麦、一键挂断或切到另一位。它不替你选模型、不让 agent 互相传话，只解决"用语音找谁、怎么快、怎么好看"这三件事。

本版（v2）相对 v1 的改动

"坑位"统一改为席位；席位图标改为各家官方标识并支持自定义图片/GIF；设置窗支持系统材质透明、深浅色与跟随系统；新增快捷键页、Dock 默认形态（含常驻小宠物）；通话中增加"一键闭麦 + 切换席位"完整原型；接入路线改为浏览器优先、全程无感，并补了登录/授权流程原型；技术方案改为 Tauri 2（Rust 核心 + 系统原生材质），以便在 Linux 云电脑开发、Mac 先跑。

设计原则：怎么像一件艺术品

对齐 Apple HIG 的"Liquid Glass"语言：玻璃是一层悬浮在内容之上的材质，不是贴图；它折射桌面壁纸、随内容变色、随动作形变。Windows 端用 Fluent 的 Mica/Acrylic 做等价物。

材质

  • 真玻璃：macOS 用 NSVisualEffectView（hudWindow / popover 材质，behindWindow 混合），Windows 用 Mica Alt / Acrylic；绝不用 CSS backdrop-filter 冒充。
  • 两层光：外圈 1 px 高光描边（上亮下暗，模拟玻璃厚度）+ 内部 4% 白色径向高光；阴影 0 24 48 / 20% 黑，让条真正"浮"起来。
  • 自适应：浅色壁纸上文字用深色、深色壁纸上用浅色，跟随系统外观实时切换，不做自己的主题色。

形

  • 连续圆角：所有圆角用 Apple 的 squircle（continuous corner），胶囊半径 = 高度/2；Windows 用 8 px 系统圆角并关闭方角 fallback。
  • 同心：圆钮 56 px，胶囊高 56 px，圆钮之间 12 px；图标在圆钮里占 44%，视觉重心居中（非几何居中）。
  • 少：Dock 条上没有文字标签（悬停才出现），没有边框按钮，没有分隔线。

动

  • 形变而非切换：小圆点 → 胶囊 → 通话态是同一块玻璃的连续形变（spring 0.45 / damping 0.82），像灵动岛。
  • 有呼吸：空闲圆点 4 s 周期微亮；通话中波形由真实麦克风电平驱动；闭麦时波形冻成一条细线。
  • 可减弱：跟随系统"减弱动态效果"，所有形变退化为 150 ms 淡入淡出。

Windows 等价

  • Mica Alt（无焦点也保持材质）+ DwmSetWindowAttribute 圆角；WinUI 3 风格阴影。
  • 任务栏不显示图标，常驻托盘；位置默认靠顶部居中，与 macOS 一致。
  • Segoe Fluent Icons 作为 SF Symbols 的替身，图标重量对齐。

原型图 · 设置窗口

独立窗口，macOS 系统设置式左右分栏；侧栏用系统 sidebar 材质（透出壁纸），右侧内容区半透明；深浅色跟随系统，也可强制。Dock 条本身不承载任何配置。

登录 / 授权流程（网页席位）

  1. 添加席位 → 选服务（dot / Copilot / Muse）→ 连接账号。
  2. 弹出一个真实的登录窗（就是那个内置 webview，这一次可见），你像平时一样登录，含 Google/Apple/Passkey 和 2FA。AgentDock 不接触密码。
  3. 检测到已登录（URL 落到会话页 + 读到头像元素）→ 窗口自动收起；席位变为 ● 已连接 并显示你的账号/头像。
  4. 会话 cookie 持久化在该席位独立的 webview 数据目录（~/Library/Application Support/AgentDock/profiles/<seat>），目录加密 key 存钥匙串 / Credential Manager。
  5. 首次连接顺带两件授权：麦克风（系统弹一次"允许 AgentDock 使用麦克风"）和一次自动测试呼叫（接通 → 2 s → 挂断），校验按钮选择器可用。
  6. 常驻动作：重新登录（会话过期、被踢、人机验证时席位亮红点）· 断开（清掉该席位数据目录）· 测试呼叫。

授权流程（App 席位：Grok Bot、Devin）

  1. 自动检测本机是否已安装（/Applications/*.app / 注册表），显示版本。
  2. macOS：点 授予辅助功能权限 → 直接跳到 系统设置 › 隐私与安全性 › 辅助功能，并高亮 AgentDock；Windows 无需授权（UIA 默认可用）。
  3. 授权后自动做一次 probe：能找到"Start voice chat"按钮 → ● 已连接；找不到 → 提示"请先在 Grok Bot 里登录"。
  4. 这类席位呼叫时会把该 App 短暂拉到前台再还回焦点，是唯一不完全无感的席位——在席位行上明确标注。

席位与驱动：每家怎么接（浏览器优先）

核心抽象："席位（seat）= 一个会说话的 agent + 一个驱动（driver）"。驱动实现五个动作：ensure_session（后台页签就绪且已登录）、call、mute、hangup、probe（是否通话中/是否闭麦/是否需要人工）。凡有网页版的，一律走隐藏 webview；只有没网页版的走 App 自动化。

"无感"到底怎么实现

运行时

  • AgentDock 为每个网页席位维持一个隐藏、常驻的 webview（macOS WKWebView / Windows WebView2），独立数据目录，不与你的 Chrome 共享、不抢焦点、不在屏幕上出现。
  • 点席位 → 向该 webview 注入一段驱动脚本（选择器 + 步骤），点"通话"按钮；音频用系统默认麦克风/扬声器，走 webview 自己的 WebRTC。
  • 每 500 ms probe：通过 DOM 判断通话中/已闭麦/被要求验证；状态驱动 Dock 条，不靠自己记。
  • 闭麦默认系统级（CoreAudio / IAudioEndpointVolume），零延迟且对所有席位一致；也可切成只点网页的 Mute。

只在这两种情况露面

  • 登录：首次连接或会话过期，webview 以普通窗口显示一次，登录完自动收起。
  • 人机验证 / 需要你看一眼：probe 识别到验证页或未知弹窗，胶囊提示"需要你看一眼"，点一下把该 webview 浮出来，处理完再隐藏。
  • 其他一切（呼叫、闭麦、挂断、切换）都不弹任何浏览器窗口。

需在钉子阶段验证

① WKWebView 的 getUserMedia 麦克风授权一次性放行；② 页面在"不可见"状态下 WebRTC 不被节流；③ 站点对 webview UA 的拦截（必要时伪装成 Safari/Chrome UA）。

技术方向

选定：Tauri 2 · Rust 核心 + 系统原生材质

  • 一套 Rust 核心：席位配置、状态机、驱动调度、全局快捷键、系统麦克风、隐藏 webview 生命周期。
  • Dock 条与设置窗是 Tauri 窗口，玻璃由系统渲染：macOS NSVisualEffectView（window-vibrancy），Windows Mica/Acrylic；透明异形窗口、置顶、不出现在 Dock/任务栏。
  • 隐藏 webview 席位 = Tauri 的多 webview 窗口（WKWebView / WebView2），JS 注入与 DOM probe 走 evaluate_script。
  • 为什么不是 SwiftUI：云电脑是 Linux，编不了 Swift；Tauri 让开发/测试在 Linux 做，Mac 上 cargo tauri dev 直接跑，Windows 复用同一套。

审美落地到代码的硬指标

  • Dock 窗口背景全透明，材质由系统 vibrancy 提供；前端只画高光描边、阴影和图标，不画"假模糊"。
  • 形变用 spring 曲线，三态是同一个 DOM 节点的尺寸形变（FLIP），不是三个面板切换。
  • 字体：macOS 用 SF Pro（系统 -apple-system），Windows 用 Segoe UI Variable；中文随系统（苹方 / 微软雅黑）。
  • 所有颜色来自系统语义色（label / secondaryLabel / systemRed），跟随深浅色不写死。
驱动分发
驱动即数据：每个驱动是一份 JSON（URL、登录判定、按钮选择器、步骤脚本），可热更新；某家改界面只推新驱动，不发版。
App 驱动（macOS）
Accessibility API（AXUIElement）定位并 press；兜底 AppleScript System Events。需要辅助功能权限，设置页一键跳转。
App 驱动（Windows）
UI Automation（UIA3）查找 Name/AutomationId；兜底 SendInput。
隐私
不录音、不读聊天内容、不保存密码；只触碰按钮、读通话状态和系统麦克风开关；席位数据目录加密。

待定决策与风险

名字

暂用 AgentDock 作为工作名；候选：Dial、Roster、呼叫台。发布前定。

切换确认

默认"点谁就切谁"，配 3 s 可撤销；可在设置改成"先确认"。

隐藏 webview 的麦克风与节流

WKWebView 的 getUserMedia 授权、页面不可见时 WebRTC 是否被节流，都要在钉子阶段实测；失败则改走 CDP 控制本机 Chrome。

自动化脆弱 + 条款

各家改版就断——驱动即数据可热更；网页自动化可能触碰服务条款，仅供个人使用，不分发账号数据。

灰度

dots、Muse voice chat 都在灰度，账号没拿到就接不了；席位会明确显示"待接入"而不是报错。

商标

官方图标仅用于标识服务；若发布需逐家核对品牌使用条款，必要时改为自绘单色图标。
